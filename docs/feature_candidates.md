> 작성: 민지(데이터). 목적: 도현 회의 안건(`issue34_proposal.md`)의 **C. 피처 재검토**를 실측으로
> 채운다. 새 피처 후보 13종을 원시가격에서 계산해 RL 없이 예측력(IC)을 비교했다.

## 0. 요약

- 자산간 상대강도·국면 신호·파라미터 튜닝 **세 방향**을 스크리닝했다.
- **판을 뒤집는 강한 신호는 없다**(전부 |IC|≤0.1). 하지만 **근거 있는 교체안 2개**를 찾았다:
  1. **RSI 길이 14 → 28**: IC 0.088 → 0.095, 부호 안정. §2 논의 가벼움(지표 종류 불변, 길이만).
  2. **Drawdown 국면 신호 추가**: IC 0.085, 부호 안정, 분포 드리프트 대응.
- **EBR(SPY/TLT)이 여전히 최강**(IC 0.10) — 다른 자산쌍(주식/금·금/채권·한국/미국)은 못 이겼다.

## 2. 발견

1. **EBR은 진짜 신호, 다른 자산쌍은 아니다.** 새로 만든 상대강도 4종 중 EBR만 유의미. "자산쌍을
   늘리자"는 기대는 데이터가 지지하지 않는다(주식/금·한국/미국 모두 약함/불안정).
2. **파라미터 튜닝이 실제로 먹혔다.** RSI를 길게(28) 하면 현행(14)보다 IC·안정성이 낫다. 종류를
   바꾸지 않고 길이만 조정하므로 §2 변경이 가볍다.
3. **Drawdown(최근 고점 대비 낙폭)이 새 국면 신호로 쓸 만하다.** 현행 RSI_14급 예측력 + 안정성.
   22σ 분포 드리프트(§3) 대응 측면에서도 의미가 있다.

## 3. §2 개선안 제안 (회의 결정 필요)

| 조치 | 근거 | §2 부담 |
|---|---|---|
| 부호반전 4종(RSI_14·ROC_10·MA_Cross·Bollinger) **제거** | 스크리닝: 뺄수록 예측력↑(`screen_features`) | 지표 축소 |
| RSI **14 → 28** 튜닝 | IC 0.088→0.095, 안정 | 길이만 변경(가벼움) |
| **Drawdown 국면 신호 추가** | IC 0.085, 안정, 드리프트 대응 | 신규 1종 |
| EBR·Rolling_Vol **유지** | 안정 신호 | 없음 |

→ 결과적으로 **"노이즈 다수 → 안정 소수"** 로 State 자산지표를 재편. 실변경은 회의 합의 후
`docs/state_spec.md`·`config.yaml` 먼저 갱신(문서 우선) → `features.py` 수정 → 재빌드 → 도현 RL.

## 4. ⚠️ 정직한 한계

- **모든 후보가 |IC|≤0.1로 여전히 약하다.** RSI_28·Drawdown은 "상대적으로" 나은 것이지 강한
  신호가 아니다. 이 교체로 1/N을 +15% 넘길지는 **도현 RL + 백테스트 3지표**로만 확정된다.
- IC는 **사전 필터**(선형 순위 상관)다. RL은 순차적 의사결정이라 결과가 다를 수 있다.
- 다만 **RL 없이 13개 후보를 초 단위로 걸러** 근거 있는 소수를 추린 것 자체가 왕복 비용을 크게
  줄인다(민지↔도현 반복 → 후보 2~3개만 전달).
